# Renovate-config

Shared Renovate policy for P4suta repositories.

## Installation

```sh
git clone https://github.com/P4suta/renovate-config.git
cd renovate-config
```

## Usage

```json
{
  "extends": ["github>P4suta/renovate-config"]
}
```
